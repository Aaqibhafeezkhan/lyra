**Title:** Inclusion request: Lyra (dev.lyra.android)

- **Name:** Lyra: synced lyrics
- **Source:** https://github.com/DhruvHarani1/lyra (Android app in `android/`)
- **License:** MIT
- **Releases:** signed APKs attached to GitHub releases tagged `android-v*` (e.g. `Lyra-Android-0.2.0.apk`)
- **Metadata:** fastlane in `fastlane/metadata/android/en-US`
- **Summary:** Word-by-word synced lyrics for whatever you play, with an ambient lyrics screen, lock-screen card and a floating widget.
- **Permissions:** Notification access (reads the now-playing card, never notifications), Display over other apps (optional floating widget), foreground service (keep-running, optional).
- **Trackers / ads / accounts:** none. Network: LRCLIB (lyrics), Apple iTunes previews (optional video), optional YouTube Data API with the user's own key.
- **Size:** about 2.4 MB.
