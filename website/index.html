Get Lyra.

Free forever. Pick your device.

Windows

Windows 10 / 11

Download installer
  1. Install the Spotify desktop app and play a song.
  2. Run the installer. Lyra opens as a small floating widget.
  3. Click it to expand, press F for fullscreen.

If Windows SmartScreen warns, choose More info → Run anyway. The app is open source and not yet code-signed.

Android

Android 8.0 or newer

Download APK
  1. Open the APK and allow installs from your browser or files app.
  2. Grant Notification access so Lyra can see what is playing.
  3. Play a song. Switch ambient mode on from the moon icon.

Google Play Protect may block installs made straight from a browser. If it does, use More details → Install anyway, or install with a file manager.
